# 🍽️ Yummy - Recipe Finder

A responsive recipe discovery website that allows users to explore thousands of meals using the [TheMealDB API](https://www.themealdb.com/).

Users can search for meals, browse recipes by category, area, or ingredient, and view detailed information about each recipe.

## 🌐 Live Demo

https://yummy-vh2f.vercel.app/
---


## ✨ Features

- 🔍 Search meals by name
- 🔤 Search meals by first letter
- 🍕 Browse meals by categories
- 🌍 Explore meals by area/cuisine
- 🥩 Browse meals by ingredients
- 📖 View detailed recipe information
- 📝 Display ingredients and measurements
- 🏷️ Display recipe tags
- ▶️ Watch recipe videos on YouTube
- 🔗 Access the original recipe source
- 📱 Fully responsive design
- 📲 Mobile-friendly navigation menu
- ⚡ Loading screen while fetching data
- ✅ Contact form with input validation
- 🎨 Interactive meal cards with hover effects

## 🔌 API

This project uses **TheMealDB API** to retrieve recipe data.

The API provides information such as:

- Meal names
- Meal images
- Categories
- Areas
- Ingredients
- Measurements
- Cooking instructions
- Tags
- YouTube links
- Recipe source links

---

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

On smaller screens, the navigation changes into a top mobile menu for better usability.
